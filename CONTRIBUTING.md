# Contributing

Thanks for helping improve Hypertask (cli)! Contributions from outside the team come in as [GitHub issues](https://github.com/hypertask-ai/cli/issues/new). Please describe the bug you found or the idea you would like us to consider.

The team does the code work. Pull requests from outside the team are closed automatically by the `outside-pr-guard` workflow.

For security reports, open an issue without sensitive details. Do not include passwords, tokens, private data, or exploit details.
